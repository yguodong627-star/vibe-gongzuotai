# 工作台 · 本地 Notion 式工作台

一个**纯前端、打开即用**的个人工作台：项目空间 → 页面树 → 文档 / 任务看板 / 轻量表格，带全局搜索，可导出 Markdown / JSON、可导入备份。**没有账号、没有服务器、没有 API key；数据只存在你浏览器的 localStorage，不上传**。完全免费，没有任何功能限制。

在线使用：https://yguodong627-star.github.io/vibe-gongzuotai/ （该域名会跳转到 ysdtn.com 下的对应路径）

## 能做什么

| 模块 | 说明 |
|---|---|
| 项目空间 + 页面树 | 多个项目空间；页面可嵌套（缩进/取消缩进、上移/下移、移到其他空间）；折叠展开 |
| 文档 | Markdown 编辑 + 实时预览（编辑 / 分栏 / 预览）。工具栏一键插入：标题、粗体/斜体/删除线/行内代码/链接、无序/有序列表、**待办**、引用、代码块、表格、分隔线；列表回车自动延续；预览里可直接勾选待办 |
| 任务看板 | 列可增删、改名、拖拽排序；卡片可拖拽（同列重排、跨列移动）；标题、备注、**截止日期**（今天/已逾期高亮）、完成勾选；触屏用 ⋮⋮ 手柄拖动，也可在卡片详情里选列 |
| 轻量表格 | 可增删列；列类型：文本 / 数字 / 日期 / 选择（自定义选项）；点列头改名/改类型/删列；排序、筛选（按类型提供不同条件）、本表搜索；数字列自动合计与均值 |
| 全局搜索 | `Ctrl/⌘ + K`（手机点右上角放大镜）：搜索所有空间的标题与内容（文档正文、看板卡片、表格单元格），方向键 + 回车跳转 |
| 导出 | 完整备份 JSON（可原样导入恢复）；全部/单个空间 Markdown ZIP；单页 Markdown 或 JSON |
| 导入 | JSON 备份：**合并**（追加为新空间）或**覆盖**（覆盖前自动留快照，可在「更多」里撤销）；也可导入 `.md` 文件为新文档，支持把文件拖进页面 |

## 不做什么（范围故意收敛）

不做 AI、不做多人协作、不做云同步、不做图片/附件、不做块级拖拽编辑器、不做公式/关联/看板分组视图。需要这些请用 Notion / AppFlowy / Anytype。

## 数据与备份（请务必读）

- 数据保存在**本浏览器**的 localStorage（上限约 5 MB，对纯文本足够多数个人使用）。左下角会显示已用空间与“上次备份”时间。
- **清除浏览器数据、使用隐私/无痕模式、换浏览器或换设备，内容都会消失，设备之间不会同步。** 请定期「备份导出」JSON；迁移设备就是导出 → 导入。
- 修改超过一定次数仍未备份时，页面会提醒。存储写入失败（空间满/被禁用）时会显示醒目的红色提示。
- 同一浏览器开多个标签页时，另一个标签页修改数据后会提示刷新，避免互相覆盖。
- 导入文件会做结构校验：无效页面被丢弃、父子循环被打断、类型被纠正；不是工作台备份的文件会被拒绝。

## 与同类的差异

- AppFlowy / Anytype / Obsidian 是桌面或移动应用，需要安装；Notion 需要账号且数据在云端。这个是**打开网页就能用**，数据留在你自己手里，导出就是普通 JSON / Markdown。
- 功能刻意比它们少：只做个人项目管理里最常用的三种页面，并把“备份导出/导入”做成一等功能。

## 本地运行

纯静态文件，没有构建步骤。

```bash
python3 -m http.server 8000   # 然后打开 http://localhost:8000
```

## 依赖（均在 `vendor/`，不走 CDN）

- [JSZip](https://stuk.github.io/jszip/) 3.10.2（MIT / GPLv3 双许可）：生成 Markdown ZIP
- 字体 Instrument Serif / Inter（沿用 ysdtn.com 字体文件），中文回退宋体 / 苹方 / 微软雅黑

Markdown 解析器是自带的轻量实现（支持标题、列表含嵌套、待办、引用、围栏代码、表格、粗斜体/删除线/行内代码/链接/分隔线）；所有文本先转义再渲染，链接仅允许 http(s)/mailto，不会执行用户内容中的脚本。**不支持**：图片语法、HTML 内嵌、脚注、列表项内的多段落/代码块。

## 测试

```bash
python3 -m http.server 8769 &
NODE_PATH=/path/to/node_modules node tests/test.js   # 需 puppeteer-core 与本机 Chrome
NODE_PATH=... node tests/shots.js                    # 重新生成 screenshots/
```

`tests/test.js` 用无头 Chrome 实测：示例数据、文档工具栏与预览、XSS 转义、看板拖拽（鼠标 + 触屏手柄）、截止日期逾期、表格增删列/排序/筛选/合计/类型转换警告、全局搜索、页面树缩进、刷新后持久化、JSON/Markdown 导出、覆盖/合并/非法文件导入、手机视口抽屉与无横向溢出、无外部请求。

## 已知限制

- 不同设备不同步；容量约 5 MB；没有版本历史/撤销（删除前会二次确认，覆盖导入前有快照）。
- 看板/表格里的排序、筛选是显示层，不改数据顺序；表格单元格为单行文本；日期选择器样式取决于浏览器。
- 页面树只支持缩进/上下移/移到其他空间，不支持拖拽改树结构。
- Markdown 导出的看板、表格会变成列表/表格文本，无法再导回为看板/表格——要完整恢复请用 JSON 备份。
- 只在现代浏览器（近两年的 Chrome / Edge / Safari / Firefox）验证；已用无头 Chrome 测试桌面与手机视口，未在真机 Safari 上测过。
